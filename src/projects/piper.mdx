# piper

Piper is a production-grade, developer-first API testing CLI. Postman is great until you're living in the terminal — piper lets you fire off HTTP requests, manage environments, and debug responses without ever leaving it.

Published on npm and downloaded **3,000+ times** by real developers.

## Why It Exists

GUI API clients break flow. Piper was built to make API testing feel native to the terminal: fast, scriptable, and composable with the rest of a unix workflow.

## What's Inside

- **Modular HTTP request execution engine** with runtime-configurable headers, environment-scoped variables, and persistent session state management
- **Structured command parser and execution pipeline** — 35% lower request-processing latency through optimized async handling
- **Robust error-handling and logging layers** for clear debugging under malformed or edge-case inputs
- **Semantic versioning + GitHub CI workflows** for maintainable, continuously iterated releases
